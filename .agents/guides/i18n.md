# i18n（多言語化・翻訳）SSOT ガイド

本ドキュメントは、YouTube Video Chapter Marker の多言語化・翻訳品質・ロケール管理に関する単一真実源（SSOT）です。

---

## 1. 翻訳品質・表記ポリシー

- **無理に直訳せず、その言語圏で自然に読めることを最優先する。**
  - 現地の YouTube クリエイターや一般ユーザーがそのまま使っている英語・技術用語（例: `YouTube`, `MP4`, `MOV`, `WebM`, `VFR`, `CFR`, `fps`, `URL`, `OSS`, `MM:SS`, `.txt` 等）は無理に訳さず自然に残す。
- **文字列結合の禁止**: 語順の違い（SOV / SVO や記号前後のスペース差）に対応するため、文章をコード側で結合せず、必ずプレースホルダー（`{{param}}`）付きテンプレートで管理する。
- **YouTube 出力互換の厳守**: UI の数値・ファイルサイズ表示には `Intl.NumberFormat` を使用するが、**YouTube 概要欄へ出力するタイムコード（`00:00:00`）は常に ASCII 半角数字（`0-9`）と `:` を維持する**。

## 2. 対応言語一覧とドロップダウン表示ルール（全 11 言語）

- **並び順**: 実装順ではなく、**言語コードのアルファベット順**を維持する（`src/i18n/index.tsx` の `SUPPORTED_LOCALES`）。
- **言語名（`nativeLabel`）**: 各言語自身の表記で表示し、英語が読めないユーザーでも母語をすぐに見つけられるようにする。

## 3. 言語解決・状態保持・複数形・辞書パリティ

- **初回言語解決の優先順位（`resolveInitialLocale`）**:
  1. URL パス（`/<locale>/`）
  2. URL クエリ（`?lang=...`、共有リンク後方互換）
  3. `localStorage`（`vcm_locale`）
  4. ブラウザ優先言語（`navigator.languages` → `navigator.language`、BCP 47 階層マッチ＆エイリアス：`zh-CN`/`zh-SG`→`zh-hans`, `zh-TW`/`zh-HK`/`zh-MO`→`zh-hant`, 旧 `in`→`id`）
  5. デフォルトフォールバック: **英語（`en`）**
- **編集状態を維持した即時切替**: 言語を切り替えても読み込み済み動画・シーク位置・マーカー・編集中タイトルを失わず、リロードなしで `<html lang>` / `<html dir>` / `<title>` / メタタグ / JSON-LD / URL（`history.replaceState`）を即時同期する。
- **複数形（CLDR 6 区分対応）**: `selectPluralTemplate` は `absCount === 0` の `zero` 優先判定と `Intl.PluralRules(htmlLang)` を組み合わせ、`zero / one / two / few / many / other` を解決する。アラビア語など 6 区分を持つ言語では全カテゴリを定義する。
- **辞書パリティ**: `src/i18n/locales/*.json` は全言語でキー構造（327 キー）と `{{param}}` プレースホルダーを 100% 一致させる。

## 4. 新しい言語を追加するときのチェックリスト

必ず **1 言語ずつ** 以下の手順で実装・検証を行う。

1. `src/i18n/locales/<code>.json` を作成（自然な現地表現・適切な複数形・SEO タイトル/説明の文字数最適化・全キー＆プレースホルダー一致）。
2. `src/i18n/index.tsx` に辞書をインポートし、`LOCALES` および `SUPPORTED_LOCALES`（アルファベット順・BCP 47 `shortLabel`・`canvasFontFamily` 指定）へ登録。必要に応じ `BCP47_SCRIPT_ALIASES` を追加。
3. 専用 Web フォントが必要な文字体系（CJK・アラビア文字・タイ文字等）は `index.html` の Google Fonts と `src/index.css` の `html:lang(...)` ルールに追加。
4. `index.html` の `hreflang`、`og:locale:alternate`、静的 JSON-LD `inLanguage` を更新。
5. `vite.config.ts` の `SEO_LOCALES` に追加（※ `dist/index.html` 生成で `SEO_LOCALES[0]` が `en` である前提を崩さないこと）。
6. `vercel.json` に `/<code>` と `/<code>/` のリライトを追加（`server.ts` は汎用正規表現で自動対応済み）。
7. `package.json` の `"version"` を更新し、本ガイドの対応言語一覧表も更新する。
8. `npm run lint`・`npm test`・`npm run build` 後、`cp dist/sitemap.xml public/sitemap.xml` で開発用サイトマップを同期し、`npm run test:build`（全辞書パリティ・`dist/<code>/index.html` 監査）および開発サーバーの HTTP 200 を確認する。
