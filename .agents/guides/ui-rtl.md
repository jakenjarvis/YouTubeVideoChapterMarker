# UI / デザイン・RTL / BiDi・操作性 SSOT ガイド

本ドキュメントは、ビジュアル設計・ヘッダー構成・RTL（右から左）対応・キーボード操作・サンプル動画生成に関する単一真実源（SSOT）です。

---

## 1. ビジュアルトーン・ヘッダー構成

- **ダークスタジオ UI**: フラットな 1px ボーダー階層を維持する（ベース `#0D0F12`、ヘッダー `#111419`、パネル `#14171C`、ボーダー `#222731`、アンバー＝マーカー／主要操作、スカイブルー＝内部シーン参考）。不要な装飾・テレメトリ・システムログ表示は入れない。
- **ヘッダー 3 ゾーン構成の維持（`src/App.tsx`）**:
  - **Zone 1**: ブランドタイトル + `Ver {{version}}` + **OSS であることが分かる GitHub アイコン＆ `OSS` リンク**（`https://github.com/jakenjarvis/YouTubeVideoChapterMarker`）
  - **Zone 2**: 編集モード時の枠線付きユーティリティボタン（別の動画を開く / YouTube / ショートカット / ヘルプ：読み込み済み動画を維持したまま図解ガイドをポップアップ表示）
  - **Zone 3**: 言語切替ドロップダウン（`LanguageSelector`）+ 主要 CTA ボタン（編集モード時はエメラルド「表形式で編集」＋青「テキスト入力」＋アンバー「テキスト出力」）

## 2. RTL（右から左）と LTR 隔離・BiDi ルール

- **画面全体の RTL 反転（標準ガイドライン準拠）**:
  - アラビア語等の RTL 言語では `<html dir="rtl">` を適用し、画面全体の構成（ヘッダー左右、2カラム配置、パネル幅リサイズドラッグ＆キーボード方向、リスト、タブ、進行方向アイコン）を標準 RTL ガイドラインに従って反転させる。
- **論理 CSS プロパティの徹底**:
  - 余白・境界線・配置には物理方向（`ml-*`, `mr-*`, `pl-*`, `pr-*`, `left-*`, `right-*`, `text-left`）ではなく **論理プロパティ（`ms-*`, `me-*`, `ps-*`, `pe-*`, `start-*`, `end-*`, `text-start`）** を使用する。
  - 進行方向アイコン（`ArrowRight`, `CornerDownRight` 等）には `rtl:rotate-180` / `rtl:scale-x-[-1]` で反転対応を入れる。
- **反転させてはいけない要素（必ず `dir="ltr"` で隔離）**:
  - 動画シークバー・区間ズーム・シークバーおよび再生プレイヘッドの時間進行（左→右）
  - 再生トランスポート（逆再生 / 停止 / 再生、フレーム送り、秒スキップ、音量スライダー）
  - スプレッドシート座標系（列見出し `A, B, C...`・セルアドレス `A1`・A 列タイムコード）。タイトル／メモセルの入力と表示には `dir="auto"` を指定しアラビア語等の自然な書字方向を保つ。クイック操作レールは論理開始側（`border-e`、LTR/RTL ともに動画ペインに隣接）に配置し、固定列ヘッダー・固定行番号はスクロール時に背面が透けないよう常に完全不透明な背景色を使用する。
  - タイムコード（`00:00:00`）、フレーム番号（`#00000`）、マーカー／シーン番号（`M01` / `S01`）
  - 解像度（`1920 × 1080`）、FPS / VFR 範囲、ショートカットキー表記、バージョン番号、BCP 47 言語コード（`ja-JP` 等）
- **BiDi 混在テキスト対策**:
  - ユーザー入力タイトル等の多言語混在テキストには `dir="auto"` を指定する。
  - RTL 文中に埋め込む数値範囲や符号付き表記（例: `00:00:00 – {{timecode}}`, `-1s / +1s`, `±10%`, `VFR (29.9–30.0)`）には Unicode BiDi 隔離文字（`\u2066`〜`\u2069`）を必ず対（バランス一致）で適用する。
  - エクスポート用テキストエリアは内容があるときのみ `dir="ltr"` とし、空状態のプレースホルダー文は現在の書字方向に従わせる。
- **言語ドロップダウンの列揃え（`src/components/LanguageSelector.tsx`）**:
  - リスト全体の列揃え（開始側：言語名、終了側：BCP 47 コード＋チェック）を崩さないよう、各オプションの `<button>` 自体はリストの `dir` を継承し、`nativeLabel` の `<span>` のみに個別 `lang` / `dir` を付与する。

## 3. テキスト膨張耐性・キーボード・サンプル動画

- **テキスト膨張耐性**: ドイツ語・フランス語等の長文言語（+40〜60%）でも崩れないよう、`min-w-0`・`truncate`・`whitespace-nowrap` を適切に使い分け、ボタンやタブに不自然な固定幅を押し付けない。
- **キーボードショートカット**:
  - テキスト入力欄フォーカス時、スプレッドシートパネル内（`[data-spreadsheet-panel="true"]`）フォーカス時、および **IME 変換中（`event.isComposing` / `keyCode === 229`）** は動画のグローバルショートカットを無効化し誤動作を防ぐ。
  - OS・ブラウザに奪われる `Alt+...` 系ショートカットは使用しない（表形式編集の 10 秒ループ再生には `Ctrl+Enter` / `Cmd+Enter` を使用する）。
  - 再生・マーキング系ショートカットは非ラテンキーボード配列でも同じ位置で押せるよう物理キー（`event.code`）に対応する。
- **サンプル動画生成（`src/utils/sampleVideoGenerator.ts`）**:
  - 960×540 Canvas 描画時はアクティブ言語の `dir`・`canvasFontFamily`・翻訳スライド文言を使用し、自動折り返しで文字が見切れないようにする。焼き込みタイムコードと進捗バーは常に LTR を維持する。
