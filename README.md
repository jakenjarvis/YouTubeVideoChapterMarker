# YouTube Video Chapter Marker

ローカル動画ファイルまたは YouTube 動画の URL から、YouTube 概要欄用のチャプターリスト（`00:00 タイトル` / `00:00:00 タイトル` など）を手軽かつ正確に作成・編集できる無料の Web ツールです。

**▶ アプリを開く：** [https://youtube-video-chapter-marker.vercel.app/](https://youtube-video-chapter-marker.vercel.app/)

> **開発背景・免責事項（必ずお読みください）**

## 主な機能

- **2種類の動画ソース＋サンプル動画に対応**
  - **ローカル動画ファイル**：PC 内の MP4 / MOV / WebM / MKV / M4V などの動画ファイルを読み込み、可変フレームレート（VFR）にも対応した「フレーム対応リスト」を内部構築します。解析に 3 秒以上かかる場合は自動的にバックグラウンド処理へ切り替わり、解析済みの範囲からすぐに作業を始められます。
  - **YouTube URL（読み取り専用）**：公開されている YouTube 動画の URL（通常動画・短縮 URL・ライブアーカイブ等）または 11 文字の動画 ID から動画を再生し、概要欄に記載されている既存のチャプターを自動で取り込めます（※YouTube 側の動画情報を書き換える機能はありません）。
  - **サンプル動画でお試し**：手元に動画ファイルがない場合でも、5 シーン構成・音声付きのテスト動画（15 秒）をその場で生成してすべての操作を体験できます。
- **バックグラウンドでのシーン変化検出（ローカル動画のみ）**
  - 映像の変化や音声の切り替わりから「内部シーン参考」をバックグラウンドで自動抽出します。ご自身のマーカーとは完全に分かれた参考シーク点として確認でき、チャプター出力には混ざりません。
- **大きく見やすいタイムコード表示＆キーボード連動再生**
  - タイムコード（`HH:MM:SS.mmm`）、正確なフレーム番号（`#00000`）、経過秒数（`s`）を等幅数字で大きく常時表示します。
  - 順再生・逆再生・停止、フレーム単位のコマ送り／スキップ（`±1` / `±10` / `±30`）、秒スキップ（`±1` / `±10` / `±15`）、音量調整をボタンとキーボードの両方で操作できます。
- **縦軸タイムラインでのマーキング＆タイトル整理**
  - 任意のフレーム位置に無制限でマーカーを追加・削除でき、クリックすると該当フレームへ即座にジャンプします。
  - チャプタータイトルは直接編集できるほか、ドラッグ＆ドロップや上下ボタンでの移動・入れ替え、途中挿入時の一括下シフト、空きマーカーへの自動割当にも対応しています。
  - 左右パネルの境界線をドラッグして自由に幅を調整できます（ダブルクリックで初期幅にリセット）。
- **柔軟なテキスト入力＆フォーマット選択式出力**
  - **入力（1行ごとに自動判定）**：`00:00 タイトル`、`00:00 - タイトル`、`タイトル 00:00`、括弧付き、連番、時間範囲指定に加え、Excel やスプレッドシートからの 2 列コピペ（タブ区切り・CSV・複数スペース区切り）も自動で認識します。時刻のみの行（マーカー登録）やタイトルのみの行（未割当タイトル登録）が混在したメモでもそのまま一括取り込みできます。
  - **出力（好みの形式を選択）**：時刻の桁数（自動 / `0:00` / `00:00` / `00:00:00`）と並び・区切り（`時刻 タイトル` / `時刻 - タイトル` / `タイトル 時刻` / `タイトル - 時刻`）を自由に選択できます。YouTube チャプター表示条件（`0:00` 開始・3 件以上・10 秒以上の間隔）の自動チェック、ワンクリックコピー、`.txt` 保存に対応しています。
- **11言語の多言語UIに対応**
  - 画面右上の言語メニューから、編集中の動画・マーカー・タイトルを保持したまま 11 言語（アラビア語の右から左レイアウトを含む）の表示をいつでも切り替えられます。

## 使い方

### 1. 動画を読み込む

- **ローカル動画を使う場合**
  1. 画面中央のエリアに動画ファイルをドラッグ＆ドロップするか、「動画ファイルを選択」からファイルを選びます。
  2. メタデータ解析が完了（または 3 秒経過してバックグラウンド処理へ移行）すると、自動で編集画面に切り替わります。
  3. 画面上部のバーで、フレーム解析やシーン検出の進捗（%）を確認できます。
- **YouTube の URL を使う場合**
  1. 「YouTube URLから読み込む」欄に YouTube 動画の URL または 11 文字の動画 ID を貼り付けます。
  2. 「概要欄のチャプターリストをマーカー＆タイトルへ自動読み込みする」にチェックを入れたまま「URLを読み込む」を押すと、動画と既存チャプターが自動で読み込まれます。
  3. 編集画面上部の「概要欄を確認」から、取得した概要欄テキストの確認やチャプターの再適用が行えます。
- **動画ファイルがない場合**
  - トップ画面下部の「サンプル動画で試す」を押すと、テスト動画が自動生成されてすぐに操作を試せます。

### 2. シーク・マーキングする

- 再生・停止やフレーム送り・秒スキップでチャプターの区切り位置を探し、**`M` キー** または **「現在位置にマーク追加」** を押します。
- ローカル動画の場合は、右パネルの **「内部シーン参考」** タブやシークバー下段のシアン色の目盛りをクリックして、自動検出されたシーンの切り替わり位置を参考にできます。

### 3. チャプタータイトルを割り当て・編集する

- 右パネルの **「マーカー＆チャプター」** タブで、各マーカー行にタイトルを直接入力するか、右上の **「テキスト入力」** ボタンからメモやチャプターリストを一括貼り付けします。
- タイトル行はドラッグ＆ドロップや `↑` / `↓` ボタンで別のマーカーへ移動・入れ替えできます。途中に新しいマーカーを挿入した場合は、一括下シフトボタンで後続のタイトルをまとめて 1 枠下にずらせます。

### 4. YouTube 概要欄用に出力する

- 右上の **「テキスト出力」** ボタンを押して出力画面を開きます。
- 時刻の桁数や並び・区切りを選び、YouTube チャプター条件のチェック結果を確認したら、**「クリップボードにコピー」** または **「.txt保存」** を押して YouTube Studio の概要欄に貼り付けて使用してください。

## キーボードショートカット

※テキスト入力欄にフォーカスがある間や日本語入力の変換中は、ショートカットは自動的に無効になります。

| 操作 | キー |
| --- | --- |
| 再生 / 停止（トグル） | `Space` または `K` |
| 順方向再生 | `L` |
| 逆方向再生 | `J` |
| ミュート / ミュート解除 | `Shift + M` |
| 音量を上げる / 下げる（±10%） | `Shift + ↑` / `Shift + ↓` |
| 1 フレーム逆送り / 順送り | `←` / `→` または `,` / `.` |
| 10 フレームスキップ | `Shift + ←` / `Shift + →` |
| 30 フレームスキップ | `Ctrl (Cmd) + ←` / `Ctrl (Cmd) + →` |
| 1 秒スキップ（-1s / +1s） | `A` / `D` |
| 10 秒スキップ（-10s / +10s） | `Shift + A` / `Shift + D` |
| 15 秒スキップ（-15s / +15s） | `[` / `]` |
| 現在フレームにマーカー追加 | `M` |
| 前 / 次のマーカーへ移動 | `P` / `N` |
| 前 / 次の内部シーン（参考）へ移動 | `Shift + P` / `Shift + N` |

## プライバシーと動作仕様

- **ローカル動画は外部送信されません**：ローカルから読み込んだ動画ファイルの解析・再生・シーン検出はすべてお使いのブラウザ内だけで完結します。
- **アカウント登録・API キー不要（読み取り専用）**：YouTube 動画の読み込みにはログインや API キーを使用せず、公開動画の情報と概要欄を読み取り専用で取得します。

---

## 制限事項・注意点

- **YouTube 動画のシーン検出**：ブラウザのセキュリティ制約により、YouTube 埋め込み動画では映像・音声解析による自動シーン検出は利用できません（ローカル動画ファイル読み込み時のみ動作します）。
- **YouTube 側の仕様・設定依存**：YouTube のページ構造変更、投稿者による埋め込み再生の禁止、非公開／メンバー限定／年齢制限動画などでは、再生や概要欄取得が行えない場合があります。
- **対応ブラウザ・コーデック**：Chrome / Edge 等の最新モダンブラウザでの利用を推奨します。ローカル動画の再生可否はブラウザがサポートする動画・音声コーデックに依存します。

## ローカル環境での起動・確認方法（セルフホスト・開発者向け）

Node.js（v22 以降推奨）がインストールされた環境で実行できます。API キーや `.env` ファイルの設定は不要です。

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動（http://localhost:3000）
npm run dev
```

本番ビルドおよび起動：

```bash
npm run build
npm start
```

型チェック・自動テストの実行（GitHub Actions CI でも同じ検証が自動実行されます）：

```bash
npm run lint
npm test
npm run build
npm run test:build
```
