# YouTube Video Chapter Marker

ローカル動画ファイルまたは YouTube 動画の URL から、YouTube 概要欄用のチャプターテキスト（`00:00:00 {ChapterName}` 形式）を効率よく作成・編集するための Web ツールです。

> **開発背景・免責事項（必ずお読みください）**
> - 本アプリケーションは **Google AI Studio の Build 機能** を用いた **ヴァイブコーディング（Vibe Coding）** によって作成されています。

## 主な機能

- **2種類の動画ソースに対応**
  - **ローカル動画ファイル**：PC 内の MP4 / MOV / WebM / MKV などの動画ファイルを読み込み、コンテナメタデータと可変フレームレート（VFR）に対応した「フレーム対応リスト」を内部構築します。解析に 3 秒以上かかる場合は自動的にバックグラウンド処理へ切り替わり、解析済みの範囲から即座に操作できます。
  - **YouTube URL（読み取り専用）**：公開されている YouTube 動画の URL（通常動画・短縮 URL・ライブアーカイブ等）から動画を埋め込み再生し、概要欄に記載されている既存のチャプターリストを自動読み込みできます（※YouTube 側への書き換え機能はありません）。
- **バックグラウンドでのシーン変化検出（ローカル動画のみ）**
  - 映像のフレーム差分・色ヒストグラム変化および音声エネルギー変化から「内部シーンリスト」をバックグラウンドで自動抽出します。マーキングとは完全に分離された別軸の参考シークポイントとして利用できます。
- **大きく見やすいシーク位置表示＆キーボード連動再生**
  - タイムコード（`HH:MM:SS.mmm`）、正確なフレーム番号（`#00000`）、経過秒数（`s`）を等幅数字で大きく常時表示します。
  - 順再生・逆再生・停止、フレーム単位のコマ送り／スキップ（`±1` / `±10` / `±30`）、秒スキップ（`±1` / `±10` / `±15`）をボタンおよびキーボードで操作できます。
- **縦軸タイムラインでのマーキング＆チャプタータイトル照合**
  - 任意のフレーム位置に無制限でマーカーを追加・削除でき、クリックで該当フレームへ即座にシークします。
  - 縦軸のマーカー時間軸に対して、チャプタータイトルをドラッグ＆ドロップや上下ボタンで自由に移動・入れ替え・一括下シフト・割当解除できます（タイトルなしのマーカーや、未割当タイトルの待機リストにも対応）。
  - 左右パネルの境界線をマウスでドラッグして自由に幅を調整できます（ダブルクリックで初期幅にリセット）。
- **テキスト インポート / エクスポート（コピー＆ペースト対応）**
  - **タイプ A（入力のみ）**：改行区切りのチャプタータイトル一覧を一括取り込みし、タイムライン上のマーカーへ割り当てられます。
  - **タイプ B（入力 / 出力）**：`00:00:00 タイトル` 形式の読み込みおよび YouTube 概要欄向けテキストの出力（ワンクリックコピー・`.txt` 保存）に対応しています。

## 使い方

### 1. 動画を読み込む

- **ローカル動画を使う場合**
  1. 画面中央のドロップエリアに動画ファイルをドラッグ＆ドロップするか、「動画ファイルを選択」からファイルを選びます。
  2. メタデータ解析とフレーム対応リストの構築が完了（または 3 秒経過してバックグラウンド処理へ移行）すると、自動で編集モードに切り替わります。
  3. 画面上部のメタデータバーで、フレーム解析およびシーン検出の進捗（%）を確認できます。
- **YouTube の URL を使う場合**
  1. 「YouTube URLから読み込む」欄に YouTube 動画の URL または 11 文字の動画 ID を貼り付けます。
  2. 「概要欄のチャプターリストをマーカー＆タイトルへ自動読み込みする」にチェックを入れたまま「URLを読み込む」を押すと、動画と概要欄のチャプターが自動で読み込まれます。
  3. 編集画面上部の「概要欄を確認」から、取得した概要欄テキストの参照やチャプターの再読み込みが行えます。

### 2. シーク・マーキングする

- 再生・停止やフレーム送り・秒スキップでチャプター区切り位置を探し、**`M` キー** または **「現在位置にマーク追加」** を押します。
- ローカル動画の場合は、右パネルの **「内部シーン参考」** タブやシークバー下段のシアン色の目盛りをクリックして、自動検出されたシーン変化点を参考に確認できます。

### 3. チャプタータイトルを割り当て・編集する

- 右パネルの **「マーカー＆チャプター」** タブで、各マーカー行にタイトルを直接入力するか、ヘッダーの **「タイトル読込」**（または「テキスト入出力」）からリストを一括貼り付けします。
- タイトル行はドラッグ＆ドロップや `↑` / `↓` ボタンで別のマーカー位置へ移動・入れ替えできます。途中に新しいマーカーを挿入した場合は、一括下シフトボタンで後続のタイトルをまとめて 1 枠下にずらせます。

### 4. YouTube 概要欄形式で出力する

- 右上の **「テキスト入出力」** ボタンを押し、**「出力（タイプB）」** タブを開きます。
- 生成された `00:00:00 タイトル` 形式のテキストを **「クリップボードにコピー」** または **「.txt保存」** して、YouTube Studio の概要欄に貼り付けて使用してください。

## キーボードショートカット

※テキスト入力欄にフォーカスがある間はショートカットは無効になります。

| 操作 | キー |
| --- | --- |
| 再生 / 停止（トグル） | `Space` または `K` |
| 順方向再生 | `L` |
| 逆方向再生 | `J` |
| 1 フレーム逆送り / 順送り | `←` / `→` または `,` / `.` |
| 10 フレームスキップ | `Shift + ←` / `Shift + →` |
| 30 フレームスキップ | `Ctrl (Cmd) + ←` / `Ctrl (Cmd) + →` |
| 1 秒スキップ（-1s / +1s） | `A` / `D` |
| 10 秒スキップ（-10s / +10s） | `Shift + A` / `Shift + D` |
| 15 秒スキップ（-15s / +15s） | `[` / `]` |
| 現在フレームにマーカー追加 | `M` |
| 前 / 次のマーカーへ移動 | `P` / `N` |
| 前 / 次の内部シーン（参考）へ移動 | `Shift + P` / `Shift + N` |

## プライバシーと動作仕様

- **ローカル動画は外部送信されません**：ローカルから読み込んだ動画ファイルの解析・再生・シーン検出はすべてお使いのブラウザ内だけで完結します。
- **API キー不要・読み取り専用**：YouTube 動画の読み込みには YouTube Data API キーや Google アカウントへのログインを使用せず、公開動画の情報および概要欄を読み取り専用で取得します。

---

## 制限事項・注意点

- **YouTube 動画のシーン検出**：ブラウザのセキュリティ制約（クロスオリジン制限）により、YouTube 埋め込み動画では映像・音声解析による自動シーン検出は利用できません（ローカル動画ファイル読み込み時のみ動作します）。
- **YouTube 側の仕様・設定依存**：YouTube のページ構造変更、投稿者による埋め込み再生の禁止、非公開／メンバー限定／年齢制限動画などでは、再生や概要欄取得が行えない場合があります。
- **対応ブラウザ・コーデック**：Chrome / Edge 等の最新モダンブラウザでの利用を推奨します。ローカル動画の再生可否はブラウザがサポートする動画・音声コーデックに依存します。

## ローカル環境での起動方法

Node.js（v22 以降推奨）がインストールされた環境で実行できます。API キーや `.env` ファイルの設定は不要です。

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動（http://localhost:3000）
npm run dev
```

本番ビルドおよび起動：

```bash
npm run build
npm start
```
